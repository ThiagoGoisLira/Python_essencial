## 📖 Sobre o Projeto

Este repositório foi criado para armazenar e organizar todos os exercícios resolvidos durante o curso de Python ministrado pelo Professor **Gustavo Guanabara** no canal **Curso em Vídeo**. 

O objetivo do **Python Essencial** é servir como um portfólio de aprendizado, documentando minha evolução na linguagem, desde os conceitos mais básicos até as estruturas mais complexas e projetos práticos propostos durante as aulas.

## 🚀 Tecnologias Utilizadas

* **Linguagem:** Python 3.x
* **IDE/Editor de Texto:** PyCharm!

## 📂 Estrutura do Repositório

Os exercícios estão divididos de acordo com os Mundos (módulos) do curso:

* **Mundo 1:** Fundamentos Básicos (Tipos primitivos, operadores aritméticos, módulos e strings).
* **Mundo 2:** Estruturas de Controle (Condições `if/elif/else` e repetições `for` e `while`).
* **Mundo 3:** Estruturas Compostas (Tuplas, listas, dicionários, funções e tratamento de erros).
